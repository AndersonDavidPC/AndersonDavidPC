## 🚀 Proyectos

### 📱 Apps móviles · DrillSoft LLC

Herramientas especializadas para perforación a presión administrada (MPD), publicadas en ambas tiendas.

#### Friction Drilling Calculator
Cálculo de fricción en operaciones de perforación, con asistencia técnica contextual mediante IA.
- **Stack:** React Native · Expo · TypeScript · Gemini API
- **Resultados:** 5.0 ★ en tiendas · 650+ descargas
- **Descargar:** [App Store](https://apps.apple.com/us/app/friction-drilling-calculator/id6740011503) · [Google Play](https://play.google.com/store/apps/details?id=com.drillsoft.frictioncal)

#### ECD Calculator
Calculadora de densidad equivalente de circulación (ECD) para operaciones MPD, con integración de agentes de IA.
- **Stack:** React Native · Expo · TypeScript · Gemini API
- **Resultados:** 5.0 ★ en tiendas
- **Descargar:** [App Store](https://apps.apple.com/us/app/ecd-calculator/id6754762850) · [Google Play](https://play.google.com/store/apps/details?id=com.drillsoft.ecdcal)

#### MPD SmartCards
Contenido técnico premium para MPD, con suscripciones y compras integradas.
- **Stack:** React Native · Expo · TypeScript · RevenueCat · react-native-iap
- **Resultados:** 5.0 ★ en tiendas · 5 suscripciones activas
- **Descargar:** [App Store](https://apps.apple.com/us/app/mpd-smartcards/id6759011027) · [Google Play](https://play.google.com/store/apps/details?id=com.drillsoft.smartcards)

> En estas apps también implementé un sistema de versiones con actualizaciones **obligatorias y recomendadas**, y la internacionalización en español, inglés y portugués.

#### Monitoreo IoT en tiempo real · *proyecto privado*

- **Stack:** Next.js · Debian
- **Sitio:** [biblioteca.ufps.edu.co](https://biblioteca.ufps.edu.co/)

#### Portafolio empresarial AVL Asesorías
